# memecoin-copier (PAPER)

Copiador **en papel** (0 € reales) de ballenas de Solana. Solo lee la blockchain (Helius) y cotiza con Jupiter; nunca firma ni envía transacciones.
Lo descarga y mantiene actualizado el lanzador `index.mjs` del servidor (ver `deploy_pterodactyl/README_ES.md`).

El servidor se actualiza solo desde la rama main cada 3 minutos.
